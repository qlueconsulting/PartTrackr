HTTP 202 Accepted

Upload a choral PDF or symbolic notation score. Triggers the background pipeline (Audiveris OMR -> music21 register splitting -> FluidSynth stem synthesis).

# cURL Example:
curl -X POST "http://localhost:8000/api/v1/scores/upload" \
  -F "file=@choral_score.pdf"
GET /api/v1/scores
HTTP 200 OK

List all ingested scores with status (queued, processing_omr, parsing, synthesizing, ready, failed) and stem summaries.

# cURL Example:
curl "http://localhost:8000/api/v1/scores?skip=0&limit=50"
GET /api/v1/scores/{score_id}
HTTP 200 OK

Retrieve score status, detected choral parts, isolated audio stem URLs, processing activity logs, and error stack traces.

# cURL Example:
curl "http://localhost:8000/api/v1/scores/{score_id}"
POST /api/v1/scores/{score_id}/reprocess
HTTP 200 OK

Re-triggers the OMR, notation parsing, and synthesis pipeline for an existing score.

# cURL Example:
curl -X POST "http://localhost:8000/api/v1/scores/{score_id}/reprocess"
GET /api/v1/scores/{score_id}/stems/{stem_id}/audio
HTTP 200 / 206 Partial

Streams isolated WAV audio for a choral part (e.g., Soprano I, Tenor II, Piano Score) with HTTP range header support for Web Audio buffering.

# cURL Example:
curl -O "http://localhost:8000/api/v1/scores/{score_id}/stems/{stem_id}/audio"
DELETE /api/v1/scores/{score_id}
HTTP 204 No Content

Deletes a score record and purges all rendered stem audio, MIDI, and MusicXML files from storage.

# cURL Example:
curl -X DELETE "http://localhost:8000/api/v1/scores/{score_id}"
